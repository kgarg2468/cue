## Design decisions
- kind is REQUIRED and case-sensitive from the §6.3 set (important, decision,
  action, question, delegate, research); omitted, null, blank, or unknown
  kinds are invalid_add_marker. This differs from session kind (optional)
  because a marker IS its intent.
- note mirrors the speaker convention: optional, omitted when absent,
  explicit null rejected, trimmed non-blank, ≤4096 bytes; escape-heavy notes
  are caught by the draft → frame-bound check → insert ordering.
- at_ms is a non-negative whole millisecond (same milliseconds_field parsing
  as source timings); validation order fields → unknown_session → draft →
  bound check → insert, matching sources exactly.
- list_markers pages chronologically (at_ms ASC, id ASC, limit 50, limit+1
  probe, 8 KiB byte budget popping from the END so the beginning survives).
