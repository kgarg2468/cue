# M2 persistence slice 1 — verification summary (cycle 19, 2026-08-31/09-01)

Slice: SQLite store bootstrap + durable Session records over the versioned socket
protocol (`create_session` / `list_sessions`), bounded list responses, store/CLI
plumbing, Swift client surface, and test isolation for the default store path.

## Security invariants checked
- Store file 0600, parent directory 0700 (asserted in tests and shown in demo).
- No secret values in the store (sessions hold id/title/timestamps only).
- Socket permissions and existing message types untouched; protocol change additive.
- list_sessions frames byte-bounded (<8 KiB) with explicit truncated flag; count
  cap 50 (LIST_SESSIONS_LIMIT), fetch of limit+1 makes truncation observable.
- Opening a store with a newer user_version fails without touching data.
- Open sequence is serialized across processes by an advisory flock on a 0600
  sidecar (<store>.lock) held from before the version check through migration,
  closing the TOCTOU between the check and the WAL conversion (round-2 review
  BLOCKER; flock lives in a sidecar because flocking the store file itself
  collides with SQLite's POSIX locks on macOS — see red-evidence.log).
- chmod 0700 applies only to a parent directory open_store itself created; a
  caller-chosen pre-existing directory keeps its permissions (round-2 MAJOR).
- run-health-handshake.sh cleanup uses rm -rf on its private runtime dir, so a
  run where the store was never created no longer trips zsh NOMATCH (round-2
  MINOR).
- Existing test suites now pass --store, so `cargo test`/`swift test` no longer
  create ~/Library/Application Support/CaptureDelegate on developer machines
  (pre-existing user store verified untouched: mtime 2026-07-19 before and after).

## Known bounds carried forward (deferred, recorded for the M2 ledger)
- Pagination (cursor past the first 50) is a follow-up M2 slice; truncated:true
  tells clients more exist.
- Session schema is intentionally minimal (id/title/timestamps); session types,
  sources, and rich fields arrive with later M2 slices per S05-001/S05-002.
